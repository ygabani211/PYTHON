# 🧑‍💻 Interactive Personal Data Collector

> 🎯 A simple Python beginner project that collects personal information from the user and displays useful details such as **data type**, **memory address**, and an **approximate birth year**.

---

## ✨ Features

- 👤 Collects user's **name**
- 🎂 Collects user's **age**
- 📏 Collects user's **height in meters**
- 🔢 Collects user's **favourite number**
- 📅 Calculates the **approximate birth year**
- 🧠 Displays the **Python data type** of each value
- 💾 Displays the **memory address** using Python's `id()` function
- 👋 Shows a friendly goodbye message

---

## 🛠️ Technologies Used

- 🐍 **Python 3**
- 📦 `datetime` module
- ⌨️ User input with `input()`
- 🔄 Type conversion using `int()` and `float()`
- 🧠 `type()` and `id()` functions
- 📝 f-strings
